# 🎟️ Book My Event

🌐 **Live Demo:** https://book-my-event-psi.vercel.app/

Book My Event is a modern, responsive Event Booking Web Application that allows users to explore events, filter and sort listings, select seats, manage a watchlist, and confirm bookings through an intuitive interface.

The project focuses on clean UI architecture, structured state management, and scalable full-stack expansion using Django for backend integration.

---

## 📌 Overview

This application simulates a real-world event booking platform where users can:

- Browse and discover events
- Filter and sort dynamically
- View detailed event information
- Select seats with live availability updates
- Save events to a watchlist
- Confirm ticket bookings

The frontend is built with React and structured for seamless integration with a Django backend.

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Kushal57-2005/Book-My-Event.git
```

### 2️⃣ Navigate into the Folder

```bash
cd Book-My-Event
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```

Application runs locally at:

```
http://localhost:5173
```
