# 🎟️ Book My Event

Book My Event is a dynamic **Event Booking Website** built using **React** and **Tailwind CSS**.  
It allows users to browse events, search manually, filter by categories, and check seat availability.

---

## ✨ Features

- Manual search functionality (search on button click)
- Category-based filtering (Music, Education, Cultural, etc.)
- JSON-based dynamic event rendering
- Dynamic date calculation for events
- Event detail modal with seat availability
- Responsive and modern UI

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- HTML
- JSON
